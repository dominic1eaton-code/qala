Section 03 - Core Domain

The Solution Model

The Solution is the central root element of qala. Every object managed on the platform either is a Solution, belongs to a Solution, or exists to support a Solution. The platform's information architecture radiates outward from this root.

Solution Features

Capabilities are described by a structured features list with a name, brief, and spec.

Authentication Gateway
Provides JWT-based authentication and role resolution for all API requests. Validates bearer tokens, resolves RBAC, and injects identity into request context.
Snapshot & Rollback
Captures point-in-time SDE state and restores any prior snapshot version. CI/CD resumes post-rollback.
Maturity Gates
Defines required test, security, and compliance gates for promotion across lifecycle stages.

Solution Compositions

Solutions can be composed in multiple ways to match scale and operational need.

Single Solution
Standalone capability with one model and lifecycle.
Solution Group
Multiple related Solutions governed as a set.
Solution Network
Interconnected Solutions with shared orchestration.
The Solution Book

Every Solution has a living book: model definitions, architecture, testbed results, maturity gates, packaging details, and release history. It is the canonical source of truth for the Solution lifecycle.
