Full Tooling Hierarchy
The qala tooling model has five levels of composition. Every Tool is an atomic executable with a pinned version and verified SHA-256 hash. Toolsets group tools by purpose. Toolkits bundle toolsets into domain practice packages. Tool Suites are the platform-approved standard kit for a given solution type. Toolchains are independent: ordered execution sequences where each tool's output feeds the next.

CVE-2024-8812 · CVSS 7.4 HIGH · Detected: 2026-03-15 · Tool ID: tool-0x3b2a
A vulnerability in the embedded staticcheck dependency within golangci-lint v1.57.2 allows crafted Go source files to cause unbounded memory consumption, potentially leading to OOM in CI environments. The tool is currently marked Deprecated. All SDEs using this version must migrate.

Recommended fix: Migrate to golangci-lint v1.58.2+ or replace with standalone revive + staticcheck toolset. AI Agent has generated a migration plan — review in AI Agents →
